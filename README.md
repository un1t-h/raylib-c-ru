# raylib-ru

Курс и справочник по программированию игр на **raylib + C** на русском языке.

- [`course.html`](course.html) — курс из 20 глав, от установки до собранной игры
- [`cheatsheet.html`](cheatsheet.html) — справочник по 434 функциям raylib/raymath с поиском

Оба файла самодостаточны: открываются двойным кликом, работают офлайн, ничего не подгружают кроме шрифтов Google Fonts (при их отсутствии откатываются на системные).

## Публикация на GitHub Pages

1. Создать репозиторий (например, `raylib-ru`) и залить в него эти файлы.
2. **Settings → Pages → Source** — выбрать ветку `main`, папку `/root`.
3. Через минуту сайт будет доступен по адресу вида `https://<username>.github.io/raylib-ru/`.
